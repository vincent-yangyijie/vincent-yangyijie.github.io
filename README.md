## 项目概述

本项目是一个基于十维度评估体系的专业QA问题设计质量评估系统，特别针对化工工程领域（以化纤装备研发为例）的问题质量评估。系统采用智能规则引擎和评分算法，提供全面、精准的质量分析。

## ✨ 主要特性

### 🎯 核心评估维度
- **A类：核心质量维度 (35%)** - 准确性、完整性
- **B类：匹配质量维度 (30%)** - 一致性、实用性、结构化、简洁性
- **C类：方案质量维度 (35%)** - 专业性、高级性、实操性、实验性

### 📊 十维度详细评估
1. **清晰性** - 问题表达的准确性和易懂性
2. **具体性** - 技术细节的精细度和明确性
3. **深度** - 问题涉及的理论深度和原理分析
4. **相关性** - 与化工工程领域的匹配程度
5. **可回答性** - 基于现有技术知识的回答可能性
6. **结构** - 问题组织的逻辑性和完整性
7. **背景** - 应用场景和业务环境的描述
8. **参数** - 技术参数和指标的规范性
9. **工况** - 运行条件和时序特征的定义
10. **必要说明** - 约束条件和前提假设的清晰度

### 📈 质量标准
- **优秀**: 80-100分 (🌟)
- **良好**: 60-79分 (✅)
- **一般**: 40-59分 (⚠️)
- **较差**: 0-39分 (❌)

## 🔬 系统架构

### 智能评估引擎
```
问题输入 → 预处理 → 多维度评分 → 综合评价 → 结果输出
    ↓         ↓         ↓            ↓          ↓
化工术语      关键词     加权算法      质量等级     多格式报告
识别         匹配       规则引擎      标准映射
```

### 评分算法
- **加权平均**: 各维度加权综合得分
- **等级映射**: 数值分数到质量等级转换
- **优势分析**: 识别强项领域
- **改进建议**: 针对性优化指导
