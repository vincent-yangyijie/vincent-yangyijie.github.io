## 常见问题

### 1. 如何开始使用 VitePress？

请参考我们的[快速开始](/guide/)指南，了解如何安装和配置 VitePress。

### 2. 如何自定义站点主题？

我们提供了详细的[自定义主题](/guide/theme)指南，介绍如何修改站点的样式和布局。

### 3. 如何部署 VitePress 站点？

VitePress 生成的是静态网站，可以部署到任何支持静态网站托管的平台，如 GitHub Pages、Netlify、Vercel 等。部署前，请先运行 `pnpm run docs:build` 命令构建您的站点。

### 4. 遇到问题怎么办？

如果您在使用过程中遇到问题，可以：

- 查看[常见问题解答](https://vitepress.dev/guide/faq)
- 在 GitHub 上[搜索相关 Issue](https://github.com/vuejs/vitepress/issues)
- [提交新的 Issue](https://github.com/vuejs/vitepress/issues/new)
- 加入我们的 Discord 社区寻求帮助

### 5. 如何贡献代码或文档？

我们非常欢迎社区贡献！您可以：

- 提交代码改进的 Pull Request
- 修正或完善文档
- 报告 Bug 或提出新功能建议
- 在社区中帮助其他用户
